`terra-*` runs GPT-6.1 Terra, with efforts from medium through ultra.

| Name | Was | Now |
|---|---|---|
| `terra-*` | GPT-6 Luna, medium/high | GPT-6.1 Terra, medium … ultra |
| `gpt-5.6-terra-*` | GPT-5.6 Terra, medium/high | GPT-5.6 Terra, medium … ultra |
| `gpt-6.1-terra-*` | unavailable | GPT-6.1 Terra, medium … ultra |
| `sol-*` | GPT-6.1 Sol | unchanged |
| `luna-*` | GPT-6 Luna | unchanged |
| `astra-*` | GPT-6 Astra | unchanged |

A thread that ran `terra-*` on GPT-6 Luna reads back as `luna-*`, the model it
really ran on. `codex_poll` and `codex_fork` report that model, and a fork stays there.
GPT-5.6 Terra remains available under its pinned names.

The 1M-context scripts now raise GPT-6.1 Terra too. Re-run
`scripts/enable-1m-context.sh` (macOS/Linux) or `scripts/enable-1m-context.ps1`
(Windows): a catalog built before 2026-10-26 hides the model from codex's model list.
