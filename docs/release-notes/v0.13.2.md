The 1M-context scripts ship as release downloads.

A packaging release: the bridge itself, its six tools, the wire and the scripts are
unchanged from v0.13.1. Until now the `.mcpb` was the only thing a release carried,
so raising the context window meant cloning the repository just to get one script.

## Three assets per release

Every release now attaches, next to `claude-codex-bridge-v0.13.2.mcpb`:

- `enable-1m-context.sh` — macOS
- `enable-1m-context.ps1` — Windows (Windows PowerShell 5.1, or PowerShell 7.2+)

The scripts keep unversioned names, so the `releases/latest/download/` URL always
fetches the newest copy:

```bash
curl -fsSLO https://github.com/Alexander-Stulov/claude-codex-bridge/releases/latest/download/enable-1m-context.sh
bash enable-1m-context.sh
```

```powershell
Invoke-WebRequest https://github.com/Alexander-Stulov/claude-codex-bridge/releases/latest/download/enable-1m-context.ps1 -OutFile enable-1m-context.ps1
powershell -ExecutionPolicy Bypass -File enable-1m-context.ps1
```

A downloaded `.sh` has lost its executable bit, hence `bash enable-1m-context.sh`
rather than `./`.

## Also in this release

- `tests/pack_check.py` now checks the shipped scripts as well as the bundle:
  byte-identical to `scripts/`, LF endings (bash chokes on a CR), the bash shebang
  intact, and the `.ps1` still pure ASCII — Windows PowerShell 5.1 reads a BOM-less
  file as the ANSI code page, so a single non-ASCII character can break the parse.
  CI runs the check on every push and uploads the scripts as a build artifact.

Install: download `claude-codex-bridge-v0.13.2.mcpb` below. macOS: double-click it.
Windows: Claude Desktop → Settings → Extensions → Advanced settings → Install
Extension, from a local folder — Desktop refuses files on network paths, and Windows
has no `.mcpb` file association. Then restart Claude Desktop. Needs Python 3 on the
machine (`python3` on macOS, `python` on Windows) and codex installed before Desktop
starts. Prerequisites and the full documentation are in the
[README](https://github.com/Alexander-Stulov/claude-codex-bridge#readme).
