`sol-*` runs GPT-6.1 Sol.

A family name runs its family's newest model, but `sol-*` had been seated on GPT-6 Sol
while GPT-6.1 Sol sat beside it under pinned names only.

| Name | Was | Now |
|---|---|---|
| `sol-medium` … `sol-ultra` | GPT-6 Sol | GPT-6.1 Sol |
| `luna-*`, `terra-*` | GPT-6 Luna | unchanged |
| `astra-*` | GPT-6 Astra | unchanged |

GPT-6 Sol stays reachable as `gpt-6-sol-medium` … `gpt-6-sol-ultra`. A thread that ran
on it now reads back under that pinned name, so `codex_poll` and `codex_fork` report the
model it really ran on, and a fork stays there.
