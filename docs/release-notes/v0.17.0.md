`codex_poll` now names the files a turn produced, whatever their type, and `images` on
`codex_submit` accepts any file.

| Area | Was | Now |
|---|---|---|
| Generated images | Saved by codex, path never returned | Listed in `output_files` with `source: image_generation` |
| Patched files | Counted only | Listed with `source: file_change` |
| Files written by commands, such as a script's PDF | Not reported | Listed with `source: modified_during_turn` when they are under `cwd` |
| A non-image file in `images` | Sent as an image the model could not read | Sent by its path for codex to open |

`modified_during_turn` means the file changed while the turn ran, so edits made by anyone
else working in `cwd` appear too. A `read` turn lists none. The list holds paths and sizes
only, stops at 100 entries and reports how many it left out.

The documentation now says what the sandbox allows: writes to `cwd` and to the system temp
folders.

## Upgrade

Install `claude-codex-bridge-v0.17.0.mcpb` and restart Claude Desktop.
