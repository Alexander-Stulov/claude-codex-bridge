First public release.

**claude-codex-bridge** dispatches OpenAI **codex** as an interactive subagent on
your own machine, from any Claude surface — Claude Desktop chat, Cowork sessions,
Claude Code. Those sessions often run in sandboxes where the codex CLI and its auth
are unreachable; the bridge runs codex where it actually lives. One Python file,
stdlib only, nothing to configure.

## Install

1. Install and sign in to the codex CLI first — the bridge ships no model access of
   its own:
   ```bash
   curl -fsSL https://chatgpt.com/codex/install.sh | sh
   codex login
   ```
   codex **0.153.1 or newer** is required for the `astra-*` models.
2. Download `claude-codex-bridge-v0.12.0.mcpb` below, double-click it to let Claude
   Desktop install the extension, and restart Desktop.

macOS only for now. Installing from source (`python3 server.py --install`) and the
full documentation are in the [README](https://github.com/Alexander-Stulov/claude-codex-bridge#readme).

## What you get

- **Six tools** — `codex_check`, `codex_submit`, `codex_poll`, `codex_approve`,
  `codex_interrupt`, `codex_compact`.
- **Real sessions.** A thread is the unit of work and its id is the handle. codex
  stores threads, so one can be picked up tomorrow or next week — the bridge
  re-attaches it and recovers its model, effort and working directory.
- **Nothing blocks.** MCP calls hard-timeout at 300s, so `codex_submit` returns at
  once and `codex_poll` reports progress. Polls are idempotent snapshots: nothing is
  consumed, and a missed poll costs nothing.
- **Enforced output shape.** Per-turn JSON schemas via `output_schema`; the complete
  output arrives whole through `codex_poll`, never truncated or reshaped.
- **Full model range** — `astra-*` (GPT-6), `sol-*`, `terra-*`, `luna-*`, with the
  effort ladder exposed per model and guidance on which to reach for.
- **Context runway, not a percentage.** `codex_poll` reports how much room is left
  before compaction, so long threads get managed instead of prematurely split.
- **Approvals routed to the caller**, and provenance stamped by the bridge from what
  codex reports — never from the model's self-report.
- **Optional 1M context window** via `scripts/enable-1m-context.sh`, which lifts the
  272K cap codex ships. It draws down your OpenAI quota faster; `--revert` undoes it.

Your codex credentials are never sent to Claude — they stay on your machine, used
only by codex itself.
