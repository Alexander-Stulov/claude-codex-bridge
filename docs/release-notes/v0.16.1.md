Sol and Luna offer every effort codex lists for them.

codex 0.159.0 lists low through ultra for GPT-6 Sol and low through max for GPT-6 Luna,
but the bridge offered only part of each range.

| Family | Was | Now |
|---|---|---|
| `sol-*` | `high`, `xhigh`, `ultra` | `medium`, `high`, `xhigh`, `max`, `ultra` |
| `luna-*` | `medium`, `high` | `low`, `medium`, `high`, `xhigh`, `max` |
| `astra-*` | `medium` … `ultra` | unchanged |
| `terra-*` | `medium`, `high` | unchanged |

Pinned names follow their family: `gpt-6.1-sol-*`, `gpt-6-sol-*` and `gpt-5.6-sol-*`
now run `medium` through `ultra`, and `gpt-6-luna-*` and `gpt-5.6-luna-*` run `low`
through `max`. Sol still has no `low`, because Luna is the scout. Luna has no `ultra`,
because codex does not offer it one.
